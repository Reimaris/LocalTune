# 01: Responsive Table Layout & Natural Text Wrapping

**What to build:** The On-Demand Downloader history table gracefully wraps long track titles, playlist titles, and artist names across multiple lines with bounded column widths and word-breaking (`break-words`), preventing horizontal blowout and ensuring action buttons remain firmly anchored to the right side of the viewport.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Long track titles and playlist titles in the On-Demand Downloader table wrap naturally without clipping or overflowing the container horizontally.
- [ ] Long artist names wrap naturally without stretching column boundaries.
- [ ] The Actions column remains consistently positioned and fully visible on the right edge of the table across various screen widths.
- [ ] Parent and child playlist rows maintain visual alignment and indentation when text wraps across multiple lines.
